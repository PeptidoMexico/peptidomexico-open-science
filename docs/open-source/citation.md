# Citation and scope

Use the `CITATION.cff` in the repository root for the suite, or the citation file
inside the package you used. Cite the exact release when possible.

```text
Péptido México Open Science (2026). Reusable peptide research software suite,
v0.4.0. https://doi.org/10.5281/zenodo.21895679
```

The packages are MIT-licensed at package level. They are maintained by Péptido
México, a commercial supplier of research materials. No customer records, private
batch data or real certificates of analysis are included.
