# OSF project metadata

## Project title

Synthetic peptide calculation benchmark and reproducibility workflow

## Project description

This public OSF project documents a small, inspectable benchmark for unit-safe
peptide reconstitution calculations and the software workflow that validates it.
The benchmark contains twelve deterministic synthetic cases covering mass,
volume, mass concentration and molar concentration inputs. It is intended for
software tests, teaching and reproducibility checks.

The project does not contain customer data, clinical data, batch records,
instrument files, purity claims or experimental results. Its outputs should not
be interpreted as a dosing, administration or laboratory-certification protocol.
