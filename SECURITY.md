# Security policy

## Supported versions

Security fixes are applied to the latest tagged release of each package. The
`0.1.x` line is a release candidate and should not be used as a validated clinical,
diagnostic or production laboratory system.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue. Email
`hola@peptidomexico.com.mx` with the subject `Open Science security report` and
include the affected package, version, reproduction steps and impact. Remove any
customer data, credentials, real COAs or other confidential material before sending
the report.

We will acknowledge a report, assess severity and coordinate a fix or mitigation.
Do not use these packages to process secrets, personal data or confidential
laboratory records unless your own environment has been reviewed and secured.

## Scientific safety boundary

Mathematical correctness is not the same as method validation. A report involving
incorrect units, unsafe interpretation, misleading output or a claim that could be
mistaken for clinical guidance should be reported through the same channel.
