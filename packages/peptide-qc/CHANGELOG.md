# Changelog

## 0.1.0 — 2026-08-11

- Added a standard-20-amino-acid sequence parser with explicit rejection of
  unsupported residue codes.
- Added deterministic composition, elemental formula, average mass and
  monoisotopic mass calculations.
- Added transparent approximate net-charge and isoelectric-point calculations
  with documented pKa assumptions.
- Added Kyte–Doolittle hydropathy profiles and a JSON CLI.
- Added synthetic regression fixtures, package metadata and citation guidance.
