# Peptide reconstitution calculator demo

This is a small, runnable companion to the [`peptide-calculations`](../../packages/peptide-calculations/) package. It calculates a mathematical volume from mass and target concentration and uses Three.js to make the result easier to inspect visually.

## Run locally

```bash
npm install
npm run dev
```

The source of truth remains the [PeptidoMexico Open Science repository](https://github.com/PeptidoMexico/peptidomexico-open-science). The guided browser calculator is available at [peptidomexico.com.mx/calculadora](https://peptidomexico.com.mx/calculadora/).

## Scope

This demo is for research and education. It does not select a solvent, validate a laboratory method, calibrate a physical syringe, calculate a dose or provide administration guidance.
