# Galaxy Training Network candidate

This directory contains a learner-facing draft tutorial for the public Galaxy
ToolShed wrapper. It is ready for a learner test and community review; it is
not a claim that the tutorial has been accepted by the Galaxy Training Network.

The lesson uses only synthetic inputs and links to the installable tool, source,
documentation and benchmark. Submit it only after a person who was not involved
in writing it completes the exercise and the lesson is adapted to community
conventions.
