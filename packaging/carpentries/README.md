# The Carpentries lesson proposal

This directory contains a proposal for a Carpentries-style lesson on making small scientific calculations reproducible. It is a proposal, not an official Carpentries lesson.

The lesson uses a synthetic peptide-reconstitution benchmark only as a concrete fixture. The transferable skills are declaring units, validating tabular data, preserving provenance, testing invariants and distinguishing derived calculations from experimental claims.

The proposal will remain in the canonical repository while the Carpentries Incubator community reviews its audience, scope and teaching format. A full Workbench lesson should be created only if the community confirms that the idea is useful.
