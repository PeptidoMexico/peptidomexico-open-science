# The Turing Way contribution candidate

This directory contains a proposed reproducibility case study for discussion with The Turing Way community. It is not presented as an accepted chapter or as an official part of The Turing Way.

The case study uses a small synthetic peptide-calculation benchmark to demonstrate unit declarations, provenance, deterministic tests, environment capture and interpretation boundaries. It is written as an open-science/reproducibility example rather than a product page.

The contribution request is tracked in the public repository issue linked from the open-source destination registry. We will only open a pull request after the maintainers confirm an appropriate chapter location, format and review path.
