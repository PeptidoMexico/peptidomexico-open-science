# R-universe candidate

This directory documents the R-universe publication route for the
`peptideCalculations` package in `packages/peptideCalculations/`.

R-universe should be activated only after the package checks pass and the
organization universe repository is configured with the public package URL.
The package is intentionally small and useful: it exposes unit-labelled
reconstitution, concentration, dilution, and molarity functions for R users.

Official onboarding: <https://docs.r-universe.org/publish/setup.html>.
